Number of 1 Bits

Easy Bit Manipulation
PROB:

Write a function that takes an unsigned integer n and returns the number of '1' bits it has (also known as the Hamming weight).

CONST:
  • The input must be a 32-bit unsigned integer.
EXAMPLE:
  • •
    INPUT
    n = 11 (binary: 00000000000000000000000000001011)
    OUTPUT
    3
  • •
    INPUT
    n = 128 (binary: 00000000000000000000000010000000)
    OUTPUT
    1

The Question

Count how many 1s appear in the binary representation of a number. This is the "Hamming Weight" problem.

Visualizing Binary Bits

See each bit as either 0 or 1 in the 32-bit representation.

Intuition

We can use the Brian Kernighan's Algorithm: n & (n-1) clears the lowest set bit in one operation.

Phase 1: n & (n-1) Trick

Each n & (n-1) operation removes exactly one 1-bit.

Solution

Python Solution 
class Solution:
    def hammingWeight(self, n: int) -> int:
        count = 0
        while n:
            n = n & (n - 1)
            count += 1
        return count

Complexity Analysis

Time Complexity
O(k)
k = number of 1 bits (at most 32).
Space Complexity
O(1)
Only a counter variable.
