Reverse Integer

Medium Math Bit Manipulation
PROB:

Given a signed 32-bit integer x, reverse digits of x. If reversing causes the value to go outside the 32-bit signed integer range [-2^31, 2^31 - 1], return 0.

CONST:
  • -2^31 <= x <= 2^31 - 1
EXAMPLE:
  • •
    INPUT
    x = 123
    OUTPUT
    321
  • •
    INPUT
    x = -123
    OUTPUT
    -321

The Question

Reverse the digits while handling overflow detection and negative numbers.

Visualizing Digit Reversal

Extract digits from right and build reversed number.

Intuition

Use modulo to get last digit, then build reversed number: rev = rev * 10 + pop. Check overflow before multiplying by 10.

Phase 1: Overflow Detection

Check if rev > INT_MAX/10 before adding digit.

Solution

Python Solution 
class Solution:
    def reverse(self, x: int) -> int:
        rev = 0
        INT_MAX = 2**31 - 1
        INT_MIN = -2**31
        sign = -1 if x < 0 else 1
        x = abs(x)
        while x:
            pop = x % 10
            x //= 10
            if rev > INT_MAX // 10 or (rev == INT_MAX // 10 and pop > 7):
                return 0
            rev = rev * 10 + pop
        return sign * rev
