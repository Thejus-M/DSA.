Reverse Bits

Easy Bit Manipulation
PROB:

Reverse the bits of a 32-bit unsigned integer n and return the resulting integer.

EXAMPLE:
  • •
    INPUT
    n = 00000010100101000001111010011100
    OUTPUT
    964176192 (00111001011110000010100101000000)

The Question

Reverse all 32 bits of the binary representation. The leftmost bit becomes rightmost, and vice versa.

Visualizing Bit Reversal

Watch how each bit position gets flipped.

Intuition

Extract each bit from n and build the result by shifting bits. Use (n & 1) to get the LSB, then shift result left and n right.

Phase 1: Bit-by-Bit Extraction

Take one bit at a time from n and add it to result.

Solution

Python Solution 
class Solution:
    def reverseBits(self, n: int) -> int:
        res = 0
        for i in range(32):
            res = (res << 1) | (n & 1)
            n >>= 1
        return res

Complexity Analysis

Time Complexity
O(1)
Always 32 iterations.
Space Complexity
O(1)
Only one variable used.
