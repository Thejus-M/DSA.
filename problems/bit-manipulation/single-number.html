Single Number

Easy Array Bit Manipulation
PROB:

Given a non-empty array of integers nums, every element appears twice except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

CONST:
  • 1 <= nums.length <= 3 * 10^4
  • -3 * 10^4 <= nums[i] <= 3 * 10^4
  • Each element in the array appears twice except for one element which appears only once.
EXAMPLE:
  • •
    INPUT
    nums = [2,2,1]
    OUTPUT
    1
  • •
    INPUT
    nums = [4,1,2,1,2]
    OUTPUT
    4

The Question

In a sea of pairs, one number stands alone. Our mission is to find this "Single Number" efficiently. The challenge? We can't use extra memory (no hash sets!) and we must do it in a single pass.

Visualizing the Lonely Number

Identify the element that doesn't have a partner in the collection.

Intuition

While we could sort the array or use a Hash Map, both violate the constraints. The secret weapon for this problem is the XOR bitwise operator (^).

Phase 1: The Magic of XOR

The XOR operation has two beautiful properties: a ^ a = 0 and a ^ 0 = a.

Phase 2: Total Cancellation

Because XOR is commutative and associative, the order doesn't matter. All pairs will eventually cancel each other out, leaving only the single number.

Solution

Python Solution 
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        res = 0
        for n in nums:
            res ^= n
        return res

Complexity Analysis

Time Complexity
O(N)
We iterate through the array once.
Space Complexity
O(1)
We only keep track of the result in a single variable.
