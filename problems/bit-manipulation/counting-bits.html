Counting Bits

Easy Bit Manipulation Dynamic Programming
PROB:

Given an integer n, return an array ans of length n + 1 where ans[i] is the number of 1-bits in the binary representation of i.

CONST:
  • 0 <= n <= 10^5
EXAMPLE:
  • •
    INPUT
    n = 5
    OUTPUT
    [0,1,1,2,1,2]

The Question

For each number from 0 to n, count how many 1s appear in its binary representation.

Visualizing Binary Patterns

See how each number's 1-bits relate to smaller numbers.

Intuition

DP Insight: bits[i] = bits[i >> 1] + (i & 1). The number of 1s in i equals the 1s in i/2 plus the lowest bit.

Phase 1: DP Relationship

Each number builds on the previous result by removing the lowest bit.

Solution

Python Solution 
class Solution:
    def countBits(self, n: int) -> List[int]:
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i >> 1] + (i & 1)
        return dp

Complexity Analysis

Time Complexity
O(N)
Compute each value once.
Space Complexity
O(N)
For the result array.
