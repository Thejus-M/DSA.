Missing Number

Easy Array Bit Manipulation
PROB:

Given an array nums containing n distinct numbers in the range [0, n], return the only number in the range that is missing from the array.

CONST:
  • 1 <= nums.length <= 10^4
  • All numbers in nums are unique.
  • nums is in the range [0, n].
EXAMPLE:
  • •
    INPUT
    nums = [3,0,1]
    OUTPUT
    2

The Question

Find the missing number from 0 to n. The array contains n distinct numbers.

Visualizing the Gap

See which number is missing from the sequence.

Intuition

Use XOR! XOR of all numbers 0 to n XOR XOR of all array elements gives the missing number. Because a ^ a = 0 and a ^ 0 = a.

Phase 1: XOR Magic

All paired numbers cancel out, leaving only the missing one.

Solution

Python Solution 
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        missing = len(nums)
        for i, num in enumerate(nums):
            missing ^= i ^ num
        return missing

Time Complexity
O(N)
One pass through array.
