Balanced Binary Tree

EASY TREE DFS RECURSION
PROB:

Given a binary tree, determine if it is height-balanced.

A height-balanced binary tree is defined as a binary tree in which the left and right subtrees of every node differ in height by no more than 1.

CONST:
  • The number of nodes in the tree is in the range [0, 5000].
  • -104 <= Node.val <= 104
EXAMPLE:
  • •
    INPUT
    root = [3, 9, 20, null, null, 15, 7]
    OUTPUT
    true
  • •
    INPUT
    root = [1, 2, 2, 3, 3, null, null, 4, 4]
    OUTPUT
    false

The Question

Given the root of a binary tree, determine if it is height-balanced. This means every node's left and right subtrees must have heights differing by at most 1.

Visualizing the Problem

Watch how a balanced tree (left/right heights differ by ≤ 1) compares to an unbalanced tree (left side grows much deeper).

Intuition

Let's build the solution step by step.

Phase 1: DFS Height Calculation

We use Depth-First Search to calculate the height of each subtree from the bottom up. A leaf node has height 1, an empty child has height 0, and each parent's height is max(left, right) + 1.

Phase 2: Bottom-Up Balance Check

At every node, we check: is |leftHeight - rightHeight| <= 1? If yes, it's balanced at this node. We return both the height and the balanced status back up the tree. Green ✓ = balanced, Red ✗ = unbalanced.

Phase 3: Detecting Imbalance

On an unbalanced tree, at least one node has |L-R| > 1. Watch DFS detect the imbalance and propagate the failure upward.

Phase 4: Early Termination with -1

Optimization: return -1 as soon as imbalance is detected. This lets DFS skip unnecessary subtree checks entirely.

The bottom-up DFS approach visits each node exactly once, giving us O(n) time.

Solution

Python Solution 
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def dfs(root):
            if not root:
                return 0, True

            l_h, l_bal = dfs(root.left)
            r_h, r_bal = dfs(root.right)

            height = max(l_h, r_h) + 1
            balanced = abs(l_h - r_h) <= 1 and l_bal and r_bal

            return height, balanced

        return dfs(root)[1]
