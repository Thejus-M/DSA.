Plus One

EASY MATH & GEOMETRY ARRAY
PROB:

You are given a large integer represented as an integer array digits, where each digits[i] is the ith digit of the integer. The digits are ordered from most significant to least significant in left-to-right order. The large integer does not contain any leading 0's.

Increment the large integer by one and return the resulting array of digits.

CONST:
  • 1 <= digits.length <= 100
  • 0 <= digits[i] <= 9
  • digits does not contain any leading 0's.
EXAMPLE:
  • •
    INPUT
    digits = [1,2,3]
    OUTPUT
    [1,2,4]
    Explanation: The array represents the integer 123. Incrementing by one gives 123 + 1 = 124.
  • •
    INPUT
    digits = [9]
    OUTPUT
    [1,0]
    Explanation: 9 + 1 = 10.

The Question

The challenge lies in handling the carry. While adding 1 to 123 is simple, adding 1 to 999 requires us to ripple the carry across multiple digits and eventually expand the array size if all digits are 9.

Intuition

We iterate from right to left, simulating manual addition. As soon as we find a digit less than 9, we increment it and return. If we see a 9, it becomes 0, and we continue left.

Phase 1: Direct Increment

The simplest case: the last digit is less than 9. We just add 1 and we're done.

Phase 2: The Carry Ripple

If the digit is 9, it becomes 0 and the "carry" moves to the next digit on the left.

Phase 3: Array Expansion

When all digits are 9, the carry ripples all the way to the front. We must prepend a 1 to the array.

Solution

Python Solution 
class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits
            digits[i] = 0
        
        # If we reach here, all digits were 9
        return [1] + digits

Complexity Analysis

Time Complexity
O(N)
In the worst case (all 9s), we visit every digit once.
Space Complexity
O(N)
We might return a new array of size N+1 if we need to expand.
