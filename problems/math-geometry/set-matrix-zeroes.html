Set Matrix Zeroes

Medium Array Math & Geometry Matrix
PROB:

Given an m x n integer matrix matrix, if an element is 0, set its entire row and column to 0's.

You must do it in-place.

CONST:
  • m == matrix.length
  • n == matrix[0].length
  • 1 <= m, n <= 200
  • -231 <= matrix[i][j] <= 231 - 1
EXAMPLE:
  • •
    INPUT
    matrix = [[1,1,1],[1,0,1],[1,1,1]]
    OUTPUT
    [[1,0,1],[0,0,0],[1,0,1]]
  • •
    INPUT
    matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
    OUTPUT
    [[0,0,0,0],[0,4,5,0],[0,3,1,0]]

The Question

How can we "infect" cells with zero-ness without causing a chain reaction that resets the entire matrix? We must distinguish original zeroes from those we created.

The "Infection" Visualization

Watch how zeroes spread. If we simply zero-out as we go, we lose the original state. We need a way to remember where the zeroes were first.

Intuition

Phase 1: The External Tracker (O(M+N) Space)

Simple: use two boolean arrays to record which rows and columns contain a zero. Then do a second pass to fill them in.

Phase 2A: Reuse Matrix Edges

The trackers from Phase 1 are integrated directly into the First Row and First Column of the matrix. They act as our specialized storage zones.

Phase 2B: Marking Trackers (Row & Col)

Scanning the interior: if we find a zero at (i, j), we "project" it by marking both matrix[0][j] and matrix[i][0] to remember this specific row and column must be zeroed later.

Phase 2D: The Overlap & rowZero

Wait! Cell (0,0) is shared by both trackers. We let it track the first column, and use a separate rowZero boolean to protect the first row's original state.

Phase 2E: Full Interior Traversal

Putting it all together: watch the scan move through the interior (skipping the trackers initially). See how every zero found "projects" its coordinates onto the first row/column.

Phase 3: The Orderly Cleanup

Clean up in specific order: 1. Interior cells using markers, 2. First Column tracker, 3. First Row tracker (rowZero). Wait, why this order? Because the trackers are needed to calculate the interior, and (0,0) is needed for the first column cleanup!

Solution

Python Solution 
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0])
        rowZero = False  # Extra variable for first row overlap

        # Phase 2: Mark — use first row/col as storage
        for r in range(rows):
            for c in range(cols):
                if matrix[r][c] == 0:
                    matrix[0][c] = 0       # First row tracks columns
                    if r > 0:
                        matrix[r][0] = 0   # First col tracks rows
                    else:
                        rowZero = True     # Separate flag for row 0

        # Phase 3: Cleanup — order matters!
        # Step 1: Fill interior
        for r in range(1, rows):
            for c in range(1, cols):
                if matrix[0][c] == 0 or matrix[r][0] == 0:
                    matrix[r][c] = 0

        # Step 2: Fill first column
        if matrix[0][0] == 0:
            for r in range(rows):
                matrix[r][0] = 0

        # Step 3: Fill first row
        if rowZero:
            for c in range(cols):
                matrix[0][c] = 0

Complexity Analysis

Time Complexity
O(M × N)
Two full passes over the grid.
Space Complexity
O(1)
Storage is folded into the matrix itself, plus one boolean.
