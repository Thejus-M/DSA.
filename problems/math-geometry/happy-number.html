Happy Number

Easy Math Two Pointers Hash Table
PROB:

Write an algorithm to determine if a number n is happy.

A happy number is a number defined by the following process:

  • Starting with any positive integer, replace the number by the sum of the squares of its digits.
  • Repeat the process until the number equals 1 (where it will stay), or it loops endlessly in a cycle which does not include 1.
  • Those numbers for which this process ends in 1 are happy.

Return true if n is a happy number, and false if not.

CONST:
  • 1 <= n <= 231 - 1
EXAMPLE:
  • INPUT
    n = 19
    OUTPUT
    true
    Explanation: 1² + 9² = 82 → 8² + 2² = 68 → 6² + 8² = 100 → 1² + 0² + 0² = 1
  • INPUT
    n = 2
    OUTPUT
    false
    Explanation: 2 → 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 (Infinite Loop)

The Question

Can we find a mathematical end-state for every integer? Every number under the "Sum of Squares" operation will eventually reach 1 or fall into a repeating cycle. The goal is to detect that 1 early or catch the cycle before we run out of time (or memory).

Example: The Evolution of 19

Watch how 19 transforms step-by-step. Each digit is isolated, squared, and then added to compute the next value in the chain.

Intuition

Think of the sequence of numbers as a path through a dark forest. A "Happy" path eventually leads to an exit (the value 1). An "Unhappy" path leads into a swampy loop where you walk past the same trees forever.

Phase 1: The Digit Engine

Everything starts with the get_next function. We strip digits using modulo 10, square them, and sum them up.

Phase 2: The Success Chain

For a Happy Number, the chain of values is linear. It moves swiftly toward 1, where it stalls forever.

Phase 3: The Dark Cycle

Unhappy numbers are trapped in a fixed loop. Mathematically, any sequence that doesn't reach 1 will eventually hit the number 4, starting a cycle that never exits.

Phase 4: Two-Pointer Cycle Discovery

Floyd's Cycle-Finding Algorithm (Two Pointers) detects the loop in O(1) space. The fast pointer (Hare) will eventually lap the slow pointer (Tortoise) inside the cycle.

Solution

Python - Hash Set (Intuitive) 
class Solution:
    def isHappy(self, n: int) -> bool:
        def get_next(number):
            total_sum = 0
            while number > 0:
                number, digit = divmod(number, 10)
                total_sum += digit ** 2
            return total_sum

        seen = set()
        while n != 1 and n not in seen:
            seen.add(n)
            n = get_next(n)

        return n == 1
Python - Floyd's Cycle Detection (Space Optimized) 
class Solution:
    def isHappy(self, n: int) -> bool:
        def get_next(number):
            total_sum = 0
            while number > 0:
                number, digit = divmod(number, 10)
                total_sum += digit ** 2
            return total_sum

        slow = n
        fast = get_next(n)
        
        while fast != 1 and slow != fast:
            slow = get_next(slow)
            fast = get_next(get_next(fast))
            
        return fast == 1

Complexity Analysis

Approach A (Hash Set)
Time: O(log n)
Space: O(log n)
Number of digits in n is log(n). Space grows with the number of unique integers seen.
Approach B (Floyd's)
Time: O(log n)
Space: O(1)
Matches the time complexity but eliminates the set entirely by using two pointers.
