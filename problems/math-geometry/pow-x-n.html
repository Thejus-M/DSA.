Pow(x, n)

MEDIUM MATH BINARY SEARCH
PROB:

Implement pow(x, n), which calculates x raised to the power n (i.e., xn).

CONST:
  • -100.0 < x < 100.0
  • -231 <= n <= 231 - 1
  • n is an integer
  • -104 <= xn <= 104
EXAMPLE:
  • •
    INPUT
    x = 2.00000, n = 10
    OUTPUT
    1024.00000
  • •
    INPUT
    x = 2.10000, n = 3
    OUTPUT
    9.26100
  • •
    INPUT
    x = 2.00000, n = -2
    OUTPUT
    0.25000
    Explanation: 2-2 = 1/22 = 1/4 = 0.25

The Question

At its core, exponentiation means multiplying a number by itself n times. While a simple loop works for small values, we need a more efficient way to handle exponents as large as 2 billion.

Intuition

Instead of the brute-force approach, we can use the "Binary Exponentiation" technique (also known as Exponentiation by Squaring), which reduces the number of multiplications from n to log n.

Phase 1: Linear Multiplication

The naive way: Multiply x by itself n times. For 210, this is 10 steps. For 2109, this would take seconds or minutes!

Phase 2: Product & Power Rules

Fundamental rules: xa ⋅ xb = xa+b and (xa)b = xa⋅b. These allow us to reconstruct any power from smaller pieces.

Phase 3: Binary Exponentiation

How it cuts steps: By squaring the base (x → x2), we effectively double the "weight" of each multiplication, allowing us to halve the exponent (n → n/2) at every step. Instead of 1,024 multiplications for x1024, we only need 10 steps! (log21024 = 10).

Phase 4: Negative Exponents

If n is negative, we use the identity: x-n = (1/x)n.

Solution

Python Solution (Iterative) 
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n == 0: return 1
        if n < 0:
            x = 1 / x
            n = -n
        
        res = 1
        # Binary Exponentiation (Iterative)
        while n > 0:
            # If current bit of n is 1, multiply the result
            if n % 2 == 1:
                res *= x
            
            # Square the base
            x *= x
            # Integer division to move to the next bit
            n //= 2
            
        return res

Complexity Analysis

Time Complexity
O(log n)
We divide n by 2 in each iteration.
Space Complexity
O(1)
Iterative solution uses constant extra space.
