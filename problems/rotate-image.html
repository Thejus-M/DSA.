Rotate Image

Medium Array Math Matrix
PROB:

You are given an n x n 2D matrix representing an image, rotate the image by 90 degrees (clockwise).

You have to rotate the image in-place, which means you have to modify the input 2D matrix directly. DO NOT allocate another 2D matrix and do the rotation.

CONST:
  • n == matrix.length == matrix[i].length
  • 1 <= n <= 20
  • -1000 <= matrix[i][j] <= 1000
EXAMPLE:
  • •
    INPUT
    matrix = [[1,2,3],[4,5,6],[7,8,9]]
    OUTPUT
    [[7,4,1],[8,5,2],[9,6,3]]
  • •
    INPUT
    matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
    OUTPUT
    [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

The Question

How can we flip an N x N grid perfectly 90-degrees clockwise without using a single extra byte of auxiliary space (a second matrix)?

Example 1: The Goal

Rotating a 3x3 matrix sequentially. Watch how an entire row rotates to become a column.

Intuition

Instead of manually picking up each element and moving it to a mathematically computed index, what if we broke the rotation down into two simple geometric reflections?

Phase 1: Transpose the Matrix

We iterate through the matrix and swap matrix[i][j] with matrix[j][i]. This turns rows into columns — a reflection across the main diagonal.

Phase 2: Reverse Each Row

Next, we flip the matrix horizontally by reversing each row individually. Transposing + Reversing = 90° Clockwise Rotation!

Phase 3: The 4-Way Bubble Swap (Alternative)

Alternatively, we can achieve this in one pass by swapping 4 corresponding cells at a time in concentric rings (Layer by layer, outside in).

Solutions

The Transpose + Reverse approach is beautifully simple and heavily minimizes index-tracking bugs.
Python - Transpose & Reverse 
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)

        # 1. Transpose the matrix (swap matrix[i][j] with matrix[j][i])
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 2. Reverse each row
        for i in range(n):
            matrix[i].reverse()
Python - 4 Way Swap Layer by Layer 
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        l, r = 0, n - 1

        while l < r:
            for i in range(r - l):
                top, bottom = l, r

                # save the topleft
                topLeft = matrix[top][l + i]

                # move bottom left into top left
                matrix[top][l + i] = matrix[bottom - i][l]

                # move bottom right into bottom left
                matrix[bottom - i][l] = matrix[bottom][r - i]

                # move top right into bottom right
                matrix[bottom][r - i] = matrix[top + i][r]

                # move top left into top right
                matrix[top + i][r] = topLeft

            r -= 1
            l += 1

Complexity Analysis

Time Complexity
O(N²)
Where N is the dimension of the matrix. Every element is visited a constant number of times during the transpose and reverse passes.
Space Complexity
O(1)
We only do in-place swaps, utilizing a single temporary O(1) auxiliary variable.
