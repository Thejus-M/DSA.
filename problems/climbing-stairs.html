Climbing Stairs

Easy Dynamic Programming Fibonacci
PROB:

You are climbing a staircase. It takes n steps to reach the top.

Each time you can either climb 1 or 2 steps. In how many distinct ways can you climb to the top?

CONST:
  • 1 <= n <= 45
EXAMPLE:
  • •
    INPUT
    n = 2
    OUTPUT
    2
    There are two ways to climb to the top.
    1. 1 step + 1 step
    2. 2 steps
  • •
    INPUT
    n = 3
    OUTPUT
    3
    There are three ways to climb to the top.
    1. 1 step + 1 step + 1 step
    2. 1 step + 2 steps
    3. 2 steps + 1 step

Intuition

Let's break down the solution into four key phases to understand how we arrive at the optimal approach.

Phase 1: Brute Force Approach

First, let's visualize how to solve this recursively. We build stairs from 0 to 4, and for each step, we explore all possible paths by taking either 1 or 2 steps at a time. The recursive tree shows how the problem breaks down into smaller subproblems.

Phase 2: Identifying Repetition

Notice how certain values (like 2, 3, and 1) appear multiple times in our recursive tree. These repeated calculations waste time! The glowing magenta nodes highlight where we're solving the same subproblem over and over. This is the key insight that leads us to memoization.

Phase 3: Memoization → Linear Time

Instead of recalculating, we store each result in a table. Watch as we build the table from left to right, computing each value only once by adding the previous two values. This transforms our exponential algorithm into a linear O(n) solution with just a single pass through the array.

Phase 4: The Fibonacci Connection

The pattern we discovered is the famous Fibonacci sequence! Each number is the sum of the previous two: F(n) = F(n-1) + F(n-2). This makes perfect sense: to reach step n, we can come from step n-1 (take 1 step) or from step n-2 (take 2 steps). The number of ways to climb n stairs is exactly the (n+1)th Fibonacci number.

By recognizing this as a Fibonacci sequence, we can optimize further to O(1) space by only keeping track of the last two values instead of the entire array.

Solution: Dynamic Programming

Python Solution 
def climbStairs(n):
    if n <= 1:
        return 1
    
    prev2, prev1 = 1, 1
    
    for i in range(2, n + 1):
        current = prev1 + prev2
        prev2, prev1 = prev1, current
    
    return prev1

Complexity Analysis

Time Complexity
O(n)
Single pass through n steps.
Space Complexity
O(1)
Only storing two previous values.
