Find Minimum in Rotated Sorted Array

Medium Array Binary Search
PROB:

Suppose an array of length n sorted in ascending order is rotated between 1 and n times. For example, the array nums = [0,1,2,4,5,6,7] might become:

  • [4,5,6,7,0,1,2] if it was rotated 4 times.
  • [0,1,2,4,5,6,7] if it was rotated 7 times.

Given the sorted rotated array nums of unique elements, return the minimum element of this array.

You must write an algorithm that runs in O(log n) time.

CONST:
  • n == nums.length
  • 1 <= n <= 5000
  • -5000 <= nums[i] <= 5000
  • All the integers of nums are unique.
  • nums is sorted and rotated between 1 and n times.
EXAMPLE:
  • •
    INPUT
    nums = [3,4,5,1,2]
    OUTPUT
    1
    Explanation: Original array was [1,2,3,4,5] rotated 3 times.
  • •
    INPUT
    nums = [4,5,6,7,0,1,2]
    OUTPUT
    0
    Explanation: Original array was [0,1,2,4,5,6,7] and it was rotated 4 times.

The Question

We are given an array that was originally sorted in ascending order, but then it was rotated a certain number of times. The array still consists of two sorted subarrays. Our goal is to find the minimum element in this modified array in O(log n) time.

Intuition

Let's break down how we can leverage the sorted properties of the rotated array to find the minimum using binary search.

Phase 1: Properties of a Rotated Array

A rotated sorted array is essentially two sorted halves. Notice how the array values increase, suddenly drop at the minimum element (the "inflection point"), and then continue increasing.

Phase 2: Binary Search Strategy

If nums[mid] > nums[right], the inflection point must be to the right of mid. Otherwise, the right half is sorted, and the minimum must be at mid or to its left.

By repeatedly halving the search space based on the relationship between nums[mid] and nums[right], we guarantee finding the minimum element in logarithmic time.

Solution

Python Solution 
class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        
        while left < right:
            mid = (left + right) // 2
            
            # If the middle element is greater than the rightmost element,
            # it means the smallest value must lie to the right of mid.
            if nums[mid] > nums[right]:
                left = mid + 1
            # Otherwise, the smallest value is either mid or to the left of mid.
            else:
                right = mid
                
        # When left meets right, it points to the smallest element
        return nums[left]

Complexity Analysis

Time Complexity
O(log n)
We halve the search space at each step, operating just like standard binary search.
Space Complexity
O(1)
Only constant extra space is used for pointers.
