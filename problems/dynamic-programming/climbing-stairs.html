Climbing Stairs

EASY DYNAMIC PROGRAMMING FIBONACCI
PROB:

You are climbing a staircase. It takes n steps to reach the top.

Each time you can either climb 1 or 2 steps. In how many distinct ways can you climb to the top?

CONST:
  • 1 <= n <= 45
EXAMPLE:
  • •
    INPUT
    n = 2
    OUTPUT
    2
    There are two ways to climb to the top.
    1. 1 step + 1 step
    2. 2 steps
  • •
    INPUT
    n = 3
    OUTPUT
    3
    There are three ways to climb to the top.
    1. 1 step + 1 step + 1 step
    2. 1 step + 2 steps
    3. 2 steps + 1 step

The Question

Given n stairs, count the total number of distinct ways to reach the top. At each step you can climb either 1 or 2 stairs. This is a classic introduction to Dynamic Programming and is intimately connected to the Fibonacci sequence.

Visualizing the Problem

Watch all the distinct paths to climb n = 4 stairs — each path is a different combination of 1-step and 2-step moves.

Intuition

Let's break down the solution into four key phases to understand how we arrive at the optimal approach.

Phase 1: Brute Force Approach

We start by visualizing the recursive solution. From stair n, we can reach it from n-1 (1 step) or n-2 (2 steps). This splits into a binary tree of sub-problems. Watch the full recursion tree unfold for n=4.

Phase 2: Identifying Repetition

Notice how certain values like f(2) and f(1) appear multiple times. These repeated calculations waste time! The glowing nodes highlight where we're solving the same subproblem over and over — this is the key insight that leads us to memoization.

Phase 3: Memoization → Linear Time

Instead of recalculating, we store each result in a table. Watch as we build the table from left to right, computing each value only once by adding the previous two values. This transforms the exponential algorithm into an O(n) solution.

Phase 4: The Fibonacci Connection

The pattern is the famous Fibonacci sequence: F(n) = F(n-1) + F(n-2). To reach step n, you come from step n-1 (1 step) or n-2 (2 steps). We only need the last two values — O(1) space!

By recognizing this as a Fibonacci sequence, we can optimize further to O(1) space by only keeping track of the last two values instead of the entire array.

Solution

Python Solution 
def climbStairs(n):
    if n <= 1:
        return 1

    prev2, prev1 = 1, 1

    for i in range(2, n + 1):
        current = prev1 + prev2
        prev2, prev1 = prev1, current

    return prev1

Complexity Analysis

Time Complexity
O(n)
Single pass through n steps.
Space Complexity
O(1)
Only storing two previous values.
