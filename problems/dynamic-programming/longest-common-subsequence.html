DSA LEARNING

Longest Common Subsequence

Medium 2D DP String
PROB:

Given two strings text1 and text2, return the length of their longest common subsequence. A subsequence is a sequence that can be derived from another sequence by deleting some or no elements without changing the order of the remaining elements.

CONST:
  • 1 ≤ text1.length, text2.length ≤ 1000
  • text1 and text2 consist of only lowercase English characters
EXAMPLE:
  • •
    INPUT
    text1 = "abcde", text2 = "ace"
    OUTPUT
    3
    Explanation: The longest common subsequence is "ace" with length 3.

The Question

Find the longest sequence of characters that appear in both strings, in the same order. Characters don't need to be adjacent.

Example 1: Basic Matching

Strings: "ABCDE" and "ACE"

Example 2: Non-Contiguous Matching

Strings: "AGGTAB" and "GXTXAYB"

Understanding: Subsequence vs Substring

Subsequences can skip characters, substrings cannot

Intuition

How do we efficiently find the matching characters while maintaining order?

Phase 1: The Decision Tree

If we try a naive recursive approach, we branch out deeply. For "abcde" & "ace", we start by matching 'a'. Then we have a subproblem "bcde" & "ce". Since 'b' ≠ 'c', we branch twice! This leads to an explosion of states.

Phase 2: Defining The State

Instead of re-calculating, we store results in a table. dp[i][j] stores the LCS length for suffix text1[i:] and text2[j:]. Here is the grid for "abcde" vs "ace".

Phase 3: The Transitions (Logic)

Why Diagonal?: When characters match (e.g., 'd'=='d'), this character must be part of the LCS. We "consume" it from both strings (+1 to length) and check the remaining substrings (the diagonal).

Why Max?: When characters differ (e.g. 'a' vs 'b'), we simply cannot match them at this position. We are forced to discard at least one to make progress. Since we don't know which path leads to a better outcome, we try both options: 1. Skip 'a' and see what happens (Move Down). 2. Skip 'b' and see what happens (Move Right).
Since our goal is the Longest subsequence, we strictly choose the path that gave the larger value. Thus: max(Option1, Option2).

Phase 4: Filling The Table

We fill from the bottom-right. When characters match (e.g., 'e'=='e'), we take diagonal + 1. When they differ, we take max(right, down). Watch the table fill for "abcde" and "ace".

Solutions

Ideally intuitive. Matches our recursion tree (Phase 2). We define a function lcs(i, j) representing the LCS of text1[i:] and text2[j:] and simply cache the result.
Python - Top-Down Recursion + Memoization 
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        @cache
        def lcs(i: int, j: int) -> int:
            # Base case: reached end of either string
            if i == len(text1) or j == len(text2):
                return 0
            
            # If characters match: take diagonal
            if text1[i] == text2[j]:
                return 1 + lcs(i + 1, j + 1)
            
            # If not, try skipping either character and take max
            return max(lcs(i + 1, j), lcs(i, j + 1))
        
        return lcs(0, 0)
Iterative approach. Matches our Table Filling (Phase 5). We build the dp table from the base cases up to the full answer. Avoids recursion stack overhead.
Python - Bottom-Up DP (Tabulation) 
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        # dp[i][j] = length of LCS of text1[i:] and text2[j:]
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if text1[i] == text2[j]:
                    # Match: 1 + result from remainder
                    dp[i][j] = 1 + dp[i+1][j+1]
                else:
                    # No match: skip char from text1 OR text2
                    dp[i][j] = max(dp[i+1][j], dp[i][j+1])
        
        return dp[0][0]
Since we only ever look at the previous row (dp[i+1] when computing dp[i]), we don't need the full matrix. We can maintain just two rows: prev and curr, reducing Space Complexity from O(m*n) to O(min(m,n)).
Python - Space Optimized O(min(m,n)) 
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        # Ensure text2 is the shorter one for min space
        if len(text1) < len(text2):
            text1, text2 = text2, text1
        
        m, n = len(text1), len(text2)
        prev = [0] * (n + 1)
        curr = [0] * (n + 1)
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    curr[j] = prev[j - 1] + 1
                else:
                    curr[j] = max(prev[j], curr[j - 1])
            # Move curr to prev for next iteration
            # We copy specifically or swap if languages allow safely (Python does)
            prev = list(curr) 
            
        return prev[n]

Complexity Analysis

Time Complexity
O(m × n)
All solutions must solve M × N unique subproblems.
Space Complexity
Varies by Approach
Recursion/Basic DP: O(m × n) for the full table/cache.
Space Optimized: O(min(m, n)) by storing only current & previous rows.
